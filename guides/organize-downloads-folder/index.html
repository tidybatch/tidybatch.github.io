How to sort your Downloads folder by file type or date

Turn a Downloads folder with hundreds of loose files into Images/, Documents/, Videos/, Spreadsheets/, Archives/ and Installers/ in one go. Sorting by modified date (one folder per year and month) is covered at the end.

Two rules for any script that moves files: look at the plan before anything moves, and never let a file replace one that is already there (an older Images/screenshot.png, for example). The bash script below follows them.

Windows

There is no free script for Windows on this page: a PowerShell version would need testing in PowerShell, and we have not done that. On Windows, use tidybatch organize from the Pro section below.

macOS and Linux: a small bash script

Save this as organize.sh in your home folder:

#!/usr/bin/env bash
# Sort the files in the current folder into sub-folders by type.
# "bash organize.sh" only shows the plan; "bash organize.sh apply" moves the files.
shopt -s nocasematch
for f in *; do
  [ -f "$f" ] || continue
  case "$f" in
    *.jpg|*.jpeg|*.png|*.gif|*.webp|*.heic) dir=Images ;;
    *.mp4|*.mov|*.mkv|*.avi)                dir=Videos ;;
    *.pdf|*.doc|*.docx|*.odt|*.txt)         dir=Documents ;;
    *.xls|*.xlsx|*.ods|*.csv)               dir=Spreadsheets ;;
    *.zip|*.rar|*.7z|*.tar|*.gz)            dir=Archives ;;
    *.exe|*.msi|*.dmg|*.pkg|*.deb)          dir=Installers ;;
    *) continue ;;
  esac
  if [ "$1" = apply ]; then
    mkdir -p "$dir" && mv -n -- "$f" "$dir/"
  else
    echo "$f  ->  $dir/"
  fi
done

Then run it from the folder you want to sort (on macOS run it with bash as shown, even though the default shell is zsh):

cd ~/Downloads
bash ~/organize.sh          # preview
bash ~/organize.sh apply    # move the files

mv -n never overwrites: a file whose name is already taken in the target folder simply stays where it is, so anything left behind after the run is a name clash to check by hand.

Want an undo? TidyBatch Pro

tidybatch organize does the same sort with a preview by default, gives clashing names a _1 suffix instead of skipping them, puts unknown types in Other/, and records everything so one command puts it all back. Real output on the same test folder (which already had an Images/screenshot.png):

$ tidybatch organize ./Downloads
  bank export.csv    ->  Spreadsheets/bank export.csv
  clip.MP4           ->  Videos/clip.MP4
  Holiday photo.JPG  ->  Images/Holiday photo.JPG
  invoice.pdf        ->  Documents/invoice.pdf
  notes              ->  Other/notes
  photos.zip         ->  Archives/photos.zip
  screenshot.png     ->  Images/screenshot_1.png
  setup.exe          ->  Installers/setup.exe

8 file(s) would change.
Dry run: nothing was changed. Add --apply to do it.

Add --apply to do it, and tidybatch undo ./Downloads to restore every file to where it was (the folders it created are removed again). Other ways to sort:

tidybatch organize ./Downloads --by ext             # PDF/, JPG/, ZIP/ …
tidybatch organize ./Archive --by date -r           # 2024/08/ by modified date
tidybatch organize ./Camera --by taken -r           # 2023/07/ by photo date taken
