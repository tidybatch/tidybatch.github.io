Preview every change, apply it, and undo it with one command. One small, open-source tool for Windows, macOS and Linux.

tidybatch rename ~/Downloads --slug --lower           # preview only
tidybatch rename ~/Downloads --slug --lower --apply   # do it
tidybatch undo ~/Downloads                            # changed your mind

Why it's safe

Dry run by default

Nothing changes until you add --apply.

One-command undo

Every applied run is journaled, so undo puts every file back.

Never overwrites

Two-phase renames make chains like 1→2, 2→3 safe. Clashes get _1, _2.
